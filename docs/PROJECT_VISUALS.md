# Current project visuals

Project figures have opaque backgrounds and sit above portfolio decorations. Data is synthetic. These are concepts, not production recordings. Full-size links and copied reference screenshots are not rendered.

| Project | Current visual | Basis |
| --- | --- | --- |

Cirrus keeps a light product palette across portfolio themes. Explicit scoped heading/table colors override broad theme rules. Calculated contrast: primary text 12.43:1 on white; muted labels 5.53:1; table headings 6.88:1; toolbar text 13.24:1. Those calculations do not establish an accessibility audit. Toolbar toggle and external Spacious/Compact controls use native buttons. Responsive layouts preserve the same content in both densities. Table clipping is intentional to demonstrate visible capacity; all records remain in the DOM. The old four-view images, dropdown, and per-view GIFs are superseded and unreferenced.

About uses a code-native SVG workspace informed by user-supplied personal references. It includes a blue-cap/beard character in a teal hoodie and dark jacket, a partner with fuller curls, shaped hands and an olive coat, a patterned tabby, smaller khaki/dark-brown Siamese with white chest/paws, and fluffy dark cat. Approved truck/camper shapes are retained. Ten object hotspots respond to hover, focus and tap; individual cats move, the monitor changes, the camper shifts, the plant sways, cup steam appears, and the mountain view shifts. Her figure is redrawn with a smaller head, narrow coat/shoulders and longer legs; Jason has a defined seated pose with bent legs, a chair base, a curved reaching arm resting at the desk, and a second arm resting on his lap. Escape/pointer exit reset the scene. No game prop, hover outline, chapter-button row, or autoplay. Keyboard focus indicators remain; reduced motion disables movement. Personal photos are not public assets.

About’s desktop illustration width is bounded by viewport height, with tighter section/caption spacing. Narrow screens and zoom preserve readable content through natural flow; overflow is not hidden to fake a viewport fit.

Offline SVG inspection, lint and webpack builds are available. Live browser layout, responsive screenshots, and keyboard checks remain pending because host restrictions block browser/server sockets. Updated `docs/qa/theme_review.py` covers the current live Cirrus toggle, row capacity/chrome contraction, About hotspots, and desktop vertical overflow. See RECORDING.md for capture guidance.

The three project demos replace static illustrations on both Work and their case pages. They share scoped styles in `ProjectDemos.module.css`, use local state only, and add no dependencies. Original application repositories are unchanged. `lib/project-demos.ts` holds sample records and geometry/cleanup rules; run `node docs/qa/project_demo_logic.cjs` for bounded geometry, opposite-distance sums, protected-message exclusion and reapply checks. Browser QA now covers frame drag/keyboard/sliders/reset, cleanup selection/apply/undo, interval selection and overflow. Those browser checks remain unexecuted. Offline HTML/PDF renders were used only for approximate visual review, with grid/font fallbacks, and do not verify browser layout.

Interaction cues are on the actionable objects: Drag on the selected frame, Select messages/Selected on cleanup suggestions, View details on timeline bars, and Try compact mode on the Cirrus toolbar. Inbox has no separate Preview button and starts without a selection; Apply is disabled until a suggestion selects matches. Apply and Undo clear selection.

Discoverability follow-up: all four interactive figures now start with a prominent pale-green “Try this demo” strip, pointer icon, downward arrow and a specific instruction. Action targets are stronger at rest: larger Drag badge/dashed selection outline, larger bordered suggestion cards, larger underlined timeline View details labels and a bordered/filled Cirrus toolbar toggle. These cues do not depend on hover or animation and keep their own palette across themes.
